# pols-sequelize-helper Skill

This skill helps the assistant use and integrate the `pols-sequelize-helper` library in Node.js / TypeScript projects using Sequelize (v6).

## Key Features

1. **Accent and Case-Insensitive Filtering (`filter`)**: Generates advanced, database-native `WHERE` conditions for MSSQL and PostgreSQL to handle queries ignoring case and accents (e.g., `á`, `é`, `í`, `ó`, `ú`, `ü`).
2. **Wildcard Search**: Automatically translates `*` wildcard characters to database `%` wildcards.
3. **Automatic Pagination (`findAllByPage`)**: Simplifies retrieving count and rows in a single paginated step.
4. **Simplified Sorting by Associations**: Allows specifying order on nested models by using relationship aliases (`as`) in an array format, rather than passing raw Sequelize model classes.
5. **Synchronous Query Generation (`selectQuery` / `countQuery`)**: Previews raw SQL strings generated by Sequelize without executing them.
6. **Immutability (No Side Effects)**: Clones configuration objects before modification.

## Type Reference

```typescript
export type POrder = ([...{ model?: any, as: string }[], string, 'asc' | 'desc'] | [string, 'asc' | 'desc'])[];

export type PFilter = {
  text: string;
  fields: (string | Fn | Col | Cast)[];
};

export type PIncludeOptions = Omit<IncludeOptions, 'order'> & {
  filter?: PFilter | PFilter[];
  order?: POrder;
};

export type PFindOptions = Omit<FindOptions, 'order' | 'include'> & {
  filter?: PFilter | PFilter[];
  order?: POrder;
  include?: PIncludeOptions | PIncludeOptions[];
  page?: number;
  rowsPerPage?: number;
};
```

## APIs and Usage Guide

### 1. Accent & Case-Insensitive Filter (`findAll`, `findOne`, `findOrBuild`)

Instead of standard `findAll` / `findOne` / `findOrBuild` from Sequelize, use the helpers:

```typescript
import { findAll, findOne, findOrBuild } from 'pols-sequelize-helper';
import { User } from './models';

// Advanced filter
const users = await findAll(User, {
  filter: {
    text: 'Ramón', // Matches 'ramon', 'Ramon', 'ramón', etc.
    fields: ['firstName', 'lastName']
  }
});

// Wildcards
const usersWithWildcard = await findAll(User, {
  filter: {
    text: 'Ra*l', // Matches 'Raul', 'Raúl', 'Rael', etc.
    fields: ['firstName']
  }
});
```

### 2. Automatic Pagination (`findAllByPage`)

Retrieves paginated rows and the total count.

```typescript
import { findAllByPage } from 'pols-sequelize-helper';
import { Product } from './models';

const { rows, rowsCount, totalPages, currentPage } = await findAllByPage(Product, {
  page: 1,
  rowsPerPage: 10,
  where: { active: true }
});
// rows: array of 10 products
// rowsCount: total amount of records matching the condition
// totalPages: total number of pages
// currentPage: current page number
```

### 3. Simplified Order by Association

Use aliases (`as`) in the path to sort by associated models.

```typescript
import { findAll } from 'pols-sequelize-helper';
import { Parent } from './models';

const records = await findAll(Parent, {
  include: [{ as: 'Children' }],
  order: [
    [[{ as: 'Children' }, 'name', 'asc']]
  ]
});
```

### 4. Query Generator (`selectQuery` / `countQuery`)

Generate and preview the exact SQL output without query execution.

```typescript
import { selectQuery, countQuery } from 'pols-sequelize-helper';
import { Client } from './models';

const sqlSelect = selectQuery(Client, {
  where: { active: true },
  filter: { text: 'sanchez', fields: ['lastName'] }
});

const sqlCount = countQuery(Client, {
  where: { active: true }
});
```
